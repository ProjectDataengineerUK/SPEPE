# Glossário Eleitoral Brasileiro

## Termos TSE / Institucionais

| Termo | Definição |
|-------|-----------|
| **Seção eleitoral** | Menor unidade de votação (~300 eleitores). Cada urna = uma seção. |
| **Zona eleitoral** | Agrupamento de seções em um município. Grandes municípios têm múltiplas zonas. |
| **Local de votação** | Escola ou prédio onde ficam as urnas. Contém várias seções. |
| **Turno** | Rodada de votação. 1º turno = todos os cargos. 2º turno = candidatos sem maioria absoluta. |
| **Segundo turno** | Ocorre quando nenhum candidato obtém >50% dos votos válidos no 1º turno (exceto vereador e dep. estadual). |
| **Votos válidos** | Total de votos excluindo brancos e nulos. Base para cálculo de percentuais. |
| **Quociente eleitoral** | Votos válidos / vagas disponíveis. Determina distribuição proporcional de cadeiras. |
| **Coligação** | Aliança formal entre partidos para disputar eleição (até 2020; extinta para proporcional em 2020). |
| **Federação partidária** | Substituiu coligações para eleições proporcionais a partir de 2022. |
| **Domicílio eleitoral** | Município onde o eleitor está registrado. Pode ser diferente de onde mora. |
| **PesqEle** | Sistema TSE de registro obrigatório de pesquisas eleitorais. |
| **DRE/TRE/TSE** | Junta/Tribunal Regional/Tribunal Superior Eleitoral — hierarquia da Justiça Eleitoral. |

## Termos de Análise

| Termo | Definição |
|-------|-----------|
| **House effect** | Viés sistemático de um instituto de pesquisa em relação à média de outros institutos. |
| **Margem de erro** | Intervalo de confiança de uma pesquisa, geralmente ±2pp a ±3pp para n=1000. |
| **Tracking poll** | Pesquisa diária com janela móvel — rastreia evolução do eleitorado. |
| **Cross-pressured voter** | Eleitor que tem atributos que o empurram para candidatos diferentes. |
| **Voto útil** | Migração de eleitores de candidatos menores para candidatos viáveis. |
| **Efeito bandwagon** | Tendência de eleitores votarem em quem parece estar ganhando. |
| **Eleitor fiel** | Elege o mesmo candidato/partido independente de contexto. |
| **Volatilidade eleitoral** | Variação de votos entre eleições. Alta volatilidade = eleitorado volátil. |

## Termos IBGE / Socioeconômicos

| Termo | Definição |
|-------|-----------|
| **IDHM** | IDH Municipal — educação + longevidade + renda. Escala 0-1. |
| **Censo** | Levantamento decenal domiciliar do IBGE. Últimos: 2010, 2022. |
| **PNAD Contínua** | Pesquisa trimestral amostral — principal fonte de desemprego e renda. |
| **SIDRA** | Sistema IBGE de Recuperação Automática — API de tabelas agregadas. |
| **Setor censitário** | Menor unidade geográfica do Censo (~300 domicílios). |
| **Quintil de renda** | Divisão da população em 5 grupos de 20% por renda. Q1 = mais pobre. |

## Regiões Eleitorais (comportamento histórico)

| Região | Perfil histórico |
|--------|-----------------|
| **Nordeste** | Maior identificação histórica com PT/esquerda. Beneficiado por Bolsa Família. |
| **Sul** | Mais conservador. Forte voto em candidatos de direita/centro-direita. |
| **Sudeste** | Disputado. SP = estado mais heterogêneo. RJ = volátil. MG = "estado-pêndulo". |
| **Norte** | Mistura de voto evangélico, populações ribeirinhas e influência de programas sociais. |
| **Centro-Oeste** | Agronegócio dominant. Tendência conservadora. DF = mais escolarizado e volátil. |
