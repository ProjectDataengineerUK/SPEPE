# KB Electoral — Índice

Base de conhecimento estático sobre eleições brasileiras para os agentes SPEPE.

## Arquivos

| Arquivo | Conteúdo |
|---------|----------|
| `tse_structure.md` | Estrutura dos dados TSE, cargos, turnos, codificações |

## Contexto SPEPE

- Eleições cobertas: 2014, 2018, 2022 (municipais 2016, 2020 parcialmente)
- UFs: todos os 26 estados + DF
- Cargos principais: Presidente, Governador, Senador, Dep. Federal, Dep. Estadual
- Unidade mínima de análise: seção eleitoral (~300 eleitores)
- Dados TSE são públicos — acesso via repositório de dados eleitorais TSE
- Indicadores IBGE são agregados municipais — sem PII individual
